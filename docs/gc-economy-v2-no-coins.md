# 无金币经济与激励视频方案（V2）

## 核心规则

- 金币系统已移除；已解锁关卡可无限次免费挑战。
- 金方块是唯一进度货币，只用于永久解锁主线和关卡广场。
- 金方块不足时才展示激励视频解锁：主线每日 1 关，广场每日 2 关。
- 广告解锁指定关卡，不发放金方块，不允许绕过正常章节前置条件。
- 普通主线与广场失败后，每局可观看一次激励视频，固定回退 8 个方块锁定步骤。
- 辅助通关推进关卡、章节、皮肤和徽章进度，并可领取一次性首通金方块；不写最佳纪录、不参与排行、不发破纪录奖励。
- 好友挑战、工坊作者试玩、审核、专题和无尽模式不允许广告回退。
- 皮肤不再购买，按指定主线关卡通关自动解锁；旧存档已拥有皮肤永久保留。
- 不设置每日登录奖励。累计不同登录自然日达到 7/30/100/365 天时，获得纪念徽章。

## 数据键

- `gc_economyVersion = 2`
- `gc_stageClear_<id>`：独立通关记录
- `gc_stageBest_<id>`：合法最佳纪录
- `gc_rewardedQuota_v2`：广告解锁日额度
- `gc_loginProgress_v1`：登录天数及登录徽章
- `gc_stage_rewind_v1`：一次性临时回退快照，不进入云存档

## 云端

- `rank.recordLoginDay` 使用服务端北京时间累计自然日，并与离线本地进度取较大值合并。
- 普通进度继续通过玩家云存档同步；登录数据同时保存在 `player_progress` 集合。
- 广告完成由微信客户端关闭回调确认；业务层使用每日额度和一次性快照防止重复领取。
