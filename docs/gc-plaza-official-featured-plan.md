# 关卡广场 · 官方精选（规划草案）

> 目标：主线保持 **第一季 10×10 = 100 关**；广场用 **官方精选约 100 关** 拉长寿命、示范好关、带动 UGC。  
> 原则：广场通关 **只发金币、不产金方块**；金解锁 + 开打耗币（失败不退）；与玩家投稿分区清晰。

---

## 1. 产品定位

| | 主线闯关 | 广场官方精选 | 玩家 UGC |
|--|--|--|--|
| 进度感 | 章节剧情 / 金方块 | 「逛关」内容消费 | 社交创作 |
| 作者展示 | — | **官方** | 玩家昵称 |
| 发现入口 | 闯关页 | 广场 Tab「官方精选」 | 新关 / 热门 / 好通关 |
| 奖励 | 金 + 币 | **仅币** | **仅币** |

心智一句话：**闯关攒进度，广场刷花样，工坊自己造。**

---

## 2. 规模与难度配比

- **总量**：100 关（可分 4 批发：先 30 → 60 → 100）
- **费用档**（沿用现有 `getPlayFee`）：

| 档 | 条件（约） | 开打费 | 建议数量 |
|--|--|--|--|
| 轻 | minLines≤6 且 garbage≤24 | 8 币 | ~35 |
| 中 | 其余 | 12 币 | ~45 |
| 重 | minLines≥12 或 garbage≥50 | 16 币 | ~20 |

- **关型**：正形剪影为主（~70），高位搭梯（~20），廊道/负形（~10）
- **必须通过**工坊 `validateLayout`：垃圾 8–80、含垃圾行 3–16、顶垃圾行 ≥6、禁止满行垃圾

## 4. 命名与展示规范

- 标题 ≤ 20 字，优先 2～4 字意象名（如「方天画戟」）
- `authorName` 固定：**官方**
- `source: 'official'`，`featured: true`，`featuredRank: 1…100`
- `tags` 示例：`['冷兵器','剪影']`、`['花瓣','搭梯']`
- 列表副文案：`垃圾 x · 行 y · 官方`；已解锁显示通关次数

---

## 5. 广场信息架构（增量）

现有 Tab：`新关` / `热门` / `好通关`  

新增：

```
官方精选  ← 默认可进广场时落在此 Tab（或置顶入口）
  └─ 按 featuredRank 排序；可二次筛选主题包（二期）
```

二期可选：主题包横滑筛选（冷兵器 / 建筑 / 花瓣…），不必第一期就做。

## 6. 数据形状（与工坊兼容）

```js
{
  stageId: 'official_plaza_041', // 稳定 ID
  source: 'official',
  featured: true,
  featuredRank: 41,
  title: '方天画戟',
  authorName: '官方',
  authorOpenid: '',
  status: 'published',
  tags: ['冷兵器', '剪影'],
  seriesId: 'weapons',           // A…J
  seriesIndex: 4,
  rows: { /* 10×20，仅 .# */ },
  minLines, garbageCount, coinThreshold, // T = minLines*2
  dropIntervalMs: 1000,          // 精选可用 950～1000，少靠速度堆难
  layoutHash,
  authorBest: { lines, pieces, timeMs, layoutHash }, // 官方自通记录
  stats: { playCount: 0, clearCount: 0, ... },
  publishedAt
}
```

落地方式建议：

1. 仓库 `data/plaza-official-v1.json`（可分 theme 文件再合并）
2. 客户端缓存兜底 + 云函数 `workshop_stages` 种子写入
3. `listPlaza(sort='official')` 过滤 `source==='official' && featured`

---

## 8. 与主线 / UGC 的边界

- 官方精选 **禁止**发金方块、禁止进主线章节进度
- 不与主线关同名抢戏；造型可「同题材异布局」
- 玩家投稿进「新关/热门」；质量高的可后期手动标 `featured`（运营精选），与「官方」用 `source` 区分
- 设计文档里「精选进彩蛋章」可作为更远期选项，**本期不做**

---

## 9. 成功指标（上线后看）

- 广场 DAU 中「官方精选」点击占比
- 官方关人均开打次数、通关率（轻 40%+ / 重 10%～25% 为健康带）
- 玩过官方关的用户 → 工坊创建转化率
- 官方关不挤占热门榜时，UGC 热门是否仍有曝光（避免官方霸榜）
