# goldenCube-app（挖个方块）

微信小游戏：**俄罗斯方块残局闯关** — 官方选关、关卡广场、工坊造关、好友挑战。

## 产品入口

| 入口 | 说明 |
|------|------|
| 闯关 | 官方章节残局（10×10 布局，清垃圾过关） |
| 关卡广场 | 官方精选 + 玩家发布关 |
| 工坊 | 造关、自通、发布 |
| 好友挑战 | 挂在具体关卡上的残局对决（比消行更少） |

**不提供**经典 / 限时 / 马拉松等「模式」分入口。

## 工程

- AppID：`wxaf95434d9f7c7962`（见 `project.config.json`）
- 云环境：`utils/cloud-config.js` → `CLOUD_ENV`
- 本地存储键前缀：`gc_`
- 设计文档：`docs/gc-*.md`

## 开发

微信开发者工具打开本目录，编译类型为「小游戏」。云函数在 `cloudfunctions/`（上传部署时勿打包进主包，已在 `packOptions.ignore` 中排除）。
